# منشور معد للنشر بعد إتاحة المستودع للعامة

كيف أراجع خطة شبكة قبل تطبيقها؟

أشارككم NetDesk Lab، مشروعًا تدريبيًا ضمن ملفي المهني في الدعم الفني والشبكات، جهّزته بمساعدة أدوات الذكاء الاصطناعي.

الأداة مكتوبة بـ Python وتراجع خطة IPv4 لفرع افتراضي يضم شبكات VLAN للموظفين والطابعات والكاميرات، ثم تنتج تقرير HTML وJSON يوضح المشكلة ودليلها والإجراء المقترح.

من الحالات التي تكشفها:

• تكرار عنوان IP داخل VLAN نفسها.
• بوابة خارج الشبكة أو عنوان جهاز غير صالح.
• تداخل الشبكات الفرعية.
• عناوين ثابتة أو بوابة داخل نطاق DHCP.

في الأمثلة التدريبية: 11 ملاحظة في الخطة المعطوبة، وصفر في الخطة السليمة، مع نجاح 17 اختبارًا آليًا محليًا.

أضفت دليل استكشاف أعطال بالعربية وخطوات لعرض المشروع في خمس دقائق. الأداة تراجع الخطة دون فحص الأجهزة؛ نجاح التدقيق لا يثبت الاتصال الفعلي أو العزل الأمني.

المشروع يربط Subnetting وVLAN وDHCP بتوثيق الأعطال، ضمن مساري نحو IT Support وNetwork Technician.
